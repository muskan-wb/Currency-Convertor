# 💱 Currency Converter

A simple and responsive Currency Converter web application built using HTML, CSS, and JavaScript.

## 🚀 Features

- Convert currencies in real time
- Supports multiple currencies
- Fetches exchange rates using an API
- Currency flags displayed with the selected currencies
- Default USD to INR conversion
- Responsive design for mobile and desktop
- Loading state while fetching exchange rates
- Error message when the exchange rate cannot be fetched

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API
- Flags API

## 🔗 API Used

- Exchange Rate API
- Flags API
